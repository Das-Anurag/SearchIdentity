# SearchIdentity

A GitHub Pages site built to test whether the punctuation-only identity `!!!!!` can become discoverable in Google Search.

## Files
- `index.html` — homepage, metadata, and WebSite structured data
- `style.css` — responsive visual styling
- `robots.txt` — crawler guidance and sitemap location
- `sitemap.xml` — sitemap for the homepage

## Publish with GitHub Pages
1. Create a public repository named **SearchIdentity** under `Das-Anurag`.
2. Upload all files from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Set deployment source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Confirm the site is published at https://das-anurag.github.io/SearchIdentity/

## Google indexing
1. Add the published URL as a URL-prefix property in Google Search Console.
2. Verify ownership using one of the methods Google provides.
3. Submit `https://das-anurag.github.io/SearchIdentity/sitemap.xml`.
4. Use URL Inspection for the homepage and request indexing.
5. After Google crawls the site, test the query `!!!!!`.

Google controls search interpretation and indexing. Punctuation-only searches may be normalized or ignored, and inclusion or ranking is not guaranteed.
